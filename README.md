# 🎄 เว็บไซต์สุ่มชื่อซื้อของขวัญคริสต์มาส (Secret Santa Gift Exchange) 🎁

เว็บแอปพลิเคชันสำหรับสุ่มจับฉลากแลกของขวัญให้เพื่อน โดยแต่ละคนจะได้รับลิงก์ส่วนตัวสำหรับส่งทาง **LINE** กดเข้าไปเปิดกล่องของขวัญเพื่อดูชื่อเพื่อนที่ตัวเองต้องซื้อของขวัญให้ (การันตีชื่อไม่ซ้ำกัน ไม่ได้ชื่อตัวเอง และซ่อนผลลัพธ์จากหน้าแอดมินเพื่อให้แอดมินร่วมเล่นได้ด้วย!)

- 💰 **งบประมาณตั้งต้น:** งบ 500 บาท *(แก้ไขได้)*
- 📅 **วันนัดหมายตั้งต้น:** นัดกินข้าวและแลกของขวัญวันที่ 19 ธันวาคม 2569 *(แก้ไขได้)*
- ♻️ **นำไปเล่นซ้ำได้ตลอด:** เพียงกดปุ่มลบรายชื่อหรือล้างรายชื่อทั้งหมดแล้วสุ่มใหม่

---

## ✨ ฟีเจอร์หลัก
1. **เพิ่ม/ลบรายชื่อเพื่อนได้อิสระ:** พิมพ์เพิ่มทีละชื่อ หรือวางหลายชื่อพร้อมกันโดยคั่นด้วยลูกน้ำ (`,`) หรือขึ้นบรรทัดใหม่
2. **สุ่มจับคู่แบบไม่ซ้ำกัน 100% (Single-Cycle Derangement):** ทุกคนจะได้ซื้อให้เพื่อน 1 คน ไม่ซ้ำกัน และไม่มีโอกาสได้ชื่อตัวเอง
3. **ซ่อนผลลัพธ์จากแอดมิน:** หน้าจัดการของแอดมินจะแสดงเฉพาะปุ่มส่งลิงก์ให้แต่ละคนโดยไม่เปิดเผยว่าใครคู่ใคร เพื่อให้คนจัดงานร่วมเล่นและลุ้นไปพร้อมกับเพื่อนได้
4. **ส่งเข้า LINE ได้ทันที:**
   - ปุ่ม **💬 ส่ง LINE** แยกตามรายชื่อ (พร้อมขีดถูก `✅ ส่ง/คัดลอกลิงก์แล้ว` กันลืม)
   - ปุ่ม **📋 คัดลอกลิงก์** แยกแต่ละคน
   - ปุ่ม **📢 คัดลอกลิงก์รวมทุกคน** สำหรับส่งในกลุ่ม LINE เดียวจบ
5. **แอนิเมชันเปิดกล่องของขวัญสุดน่ารัก:** เมื่อเพื่อนกดลิงก์เข้ามา จะเห็นชื่อตัวเองเป็นการยืนยันก่อนกดเปิดกล่องของขวัญ พร้อมพลุกระดาษ (Confetti) และปุ่มกดซ่อนชื่อชั่วคราวกันคนข้างๆ แอบมอง

## 🚀 วิธีนำขึ้นใช้งานจริงบน GitHub Pages (ฟรี!)

1. สมัครและเข้าสู่ระบบที่ [github.com](https://github.com)
2. กดปุ่ม **New Repository** (มุมขวาบน `+` -> `New repository`)
   - ตั้งชื่อ Repository เช่น `secret-santa` หรือ `gift-exchange`
   - เลือกเป็น **Public**
   - กด **Create repository**
3. กดลิงก์ **uploading an existing file** แล้วลากไฟล์ `index.html` (และ `index.htm`) ลงไป จากนั้นกดปุ่มสีเขียว **Commit changes**
4. ไปที่เมนู **Settings** (ด้านบนของ Repository) -> เลือกเมนู **Pages** (แถบด้านซ้าย)
5. ในหัวข้อ **Build and deployment** -> **Branch**:
   - เปลี่ยนจาก `None` เป็น **`main`** (หรือ `master`) แล้วกด **Save**
6. รอประมาณ 1–2 นาที รีเฟรชหน้าเว็บ จะเห็นลิงก์เว็บไซต์ของคุณ เช่น:
   `https://ชื่อบัญชีของคุณ.github.io/secret-santa/`
7. เปิดลิงก์นั้นเพื่อเพิ่มรายชื่อเพื่อน กดสุ่ม และกดปุ่มส่งลิงก์เข้า **LINE** ได้เลย! 🎉
